## Template Variables

Use the following variables in templates:

| Variable | Description | Example |
|----------|-------------|---------|
| {{TENANT_NAME}} | Tenant's full name | Rahul Sharma |
| {{OWNER_NAME}} | Owner's full name | Amit Verma |
| {{PROPERTY_NAME}} | Property name | RoomHy PG Sector 12, Bangalore |
| {{INVOICE_NUMBER}} | Invoice reference number | RH/25-26/000001 |
| {{AMOUNT_DUE}} | Amount in rupees | Rs. 6,449.00 |
| {{OTP_CODE}} | One-time password | 847291 |
| {{EXPIRY_MINUTES}} | OTP validity in minutes | 10 |
| {{LOGIN_ID}} | User login email/ID | rahul.sharma@roomhy.com |
| {{USER_ID}} | Unique user identifier | rahul123 |
| {{DUE_DATE}} | Payment due date | 05 April 2026 |
| {{MOVE_IN_DATE}} | Preferred move-in date | 01 April 2026 |
| {{ROOM_NUMBER}} | Allocated room number | 204, Floor 2 |
| {{CITY}} | City name | Bangalore |

## Implementation Notes

1. **Timestamp Format**: Always use [HH:MM am/pm, DD/MM/YYYY] format
2. **Sender**: Use "RoomHy" as the default sender for all notifications
3. **Closing**: Always end with "Team RoomHy 🏠"
4. **Links**: Use short, trackable URLs with user-specific IDs
5. **Variables**: Replace {{VARIABLE}} with actual values before sending
6. **Formatting**: Use bullet points (*), numbered lists, and relevant emojis for readability
7. **Length**: Keep messages concise but informative
8. **Personalization**: Always address users by their first name when available
9. **Call-to-Action**: Include clear next steps or action items
10. **Urgency**: Use emojis and language to convey priority when needed

---

## Quality Checklist

- [ ] Message includes relevant emoji for visual appeal
- [ ] All {{VARIABLES}} are replaced with real data
